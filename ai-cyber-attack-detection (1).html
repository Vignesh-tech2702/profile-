AI-Based Cyber Attack Detection System for Banking Networks

A machine learning pipeline that watches banking network traffic in real time, separates normal activity from intrusion attempts, and hands analysts a ranked alert — before a threat reaches an account.

01

Why banking networks need this

Banking infrastructure is a constant target: DDoS floods aimed at online banking portals, phishing-driven credential theft, malware moving laterally through branch networks, and intrusion attempts probing core banking APIs. Rule-based firewalls and signature systems catch known patterns but miss novel or slowly-evolving attacks.

This project applies supervised and anomaly-based machine learning to network flow data, so the system can flag suspicious behaviour it has never seen labelled before — and route it to a security analyst with context, not just a raw alert.

02

System architecture

Traffic is captured at the network edge, reduced to statistical features, scored by the detection engine, then routed by outcome — silent for normal traffic, escalated for anything else.

Solid arrows: mandatory pipeline flow. Dashed line: normal traffic path logged without alerting.
01 · CAPTURE
Traffic sensor
Mirrors traffic from ATMs, core banking servers, and the mobile app as NetFlow records.
02 · PREPROCESS
Feature extraction
Reduces raw flows to normalized statistical features the model can score.
03 · DETECT
AI/ML classifier
An ensemble of Random Forest, LSTM, and CNN models scores each flow in under 2 seconds.
04 · CLASSIFY
Threat category
Sorts each flow into normal traffic, DDoS, phishing, or malware/intrusion.
05 · RESPOND
SOC dashboard
Anything but normal traffic reaches the analyst as a ranked, actionable alert.

04

Expected outcomes

FOR THE BANK

Earlier visibility into DDoS, phishing, and intrusion attempts against core banking channels, with fewer false alarms reaching analysts.

FOR THE ANALYST

A single dashboard that ranks alerts by severity instead of a raw stream of logs to sift through manually.

TECHNICAL

A trained, benchmarked model comparison (Random Forest vs LSTM vs CNN) on banking-representative traffic classes.

ACADEMIC

A reproducible pipeline and report suitable for extension into a final-year capstone project.
